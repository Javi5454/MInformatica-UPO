# MInformatica-UPO

Este repositorio se utilizará para trabajar los contenidos del **Máster en Ingeniería Informática** de la **Universidad Pablo de Olavide** (modalidad online):

- **Primera parte:** curso 2026-27
- **Segunda parte:** curso 2027-28

## Aviso sobre el uso de IA

En este repositorio se utilizarán herramientas de inteligencia artificial de manera libre y arbitraria para la elaboración de código, documentación y demás contenidos. Parte del material puede haber sido generado o modificado con ayuda de IA.
